Runpex プライバシーポリシー

制定日：2026年10月8日

Runpex（以下「本アプリ」）は、ランニングのコース作成・音声ナビ・記録のためのアプリです。本アプリの運営者（以下「運営者」）は、利用者の情報を次のとおり取り扱います。

1. 取得する情報と使い道

端末の中だけに保存する情報

次の情報は利用者の端末の中に保存し、運営者のサーバーには送りません（「3. 友達機能を使う場合」を除きます）。

  • 位置情報：ナビやフリーランで走っている間に取得し、現在地の表示、曲がり角の案内、距離・ペースの計測、走った道の記録に使います。このほか、コースを作る画面などを開いたときに、地図を現在地に合わせるため1回だけ取得します。それ以外のときは取得しません。
  • 走った記録：日時、距離、タイム、1kmごとのラップ、走った道の軌跡、走り始めた場所の天気、ナビの読み上げの記録
  • 作ったコースとアプリの設定

画面をロックしているときの位置情報

ナビやフリーランの途中で画面をロックしたり、別のアプリに切り替えたりしても案内を続けるため、走っている間はバックグラウンドで位置情報を取得します。走り終えるか、ナビを終了すると取得をやめます。

2. 外部のサービスに送る情報

本アプリは、次の機能のために外部のサービスへ情報を送ります。いずれも位置に関する情報を含みますが、利用者の名前やメールアドレスは送りません。

送り先送る情報目的
Apple（地図）地図に表示している範囲地図の表示
FOSSGIS e.V. が運営する OpenStreetMap のルート計算サーバー（routing.openstreetmap.de）コースの経由点の座標道路に沿ったコースの計算
国土地理院（標高タイル）コース周辺の地図タイルの位置高低差の計算
Open-Meteoコース上の地点の座標、走り始めた場所（約100m単位）と日時高低差の計算（国土地理院のデータが無い場所のみ）、気温・湿度の取得
OpenStreetMap の検索サーバー（Overpass API の公開サーバー）コースを囲む範囲（四角形の範囲のみ）コース沿いの信号の数の目安

3. 友達機能を使う場合

友達機能（ログイン）を使うと、次の情報を運営者が利用するクラウドサービス Supabase のサーバーに保存します。ログインしなくても、友達機能以外はすべて使えます。

  • メールアドレス：ログインのためのコードを送るために使います。他の利用者には表示しません。
  • プロフィール（ユーザー名、表示名、週の目標距離）：友達の検索とランキングに使います。ログインしている利用者は、ユーザー名で検索して表示名を見ることができます。
  • 走った記録（日時、タイム、距離、ラップ、コース名、走った道の軌跡）：友達に見せるため、ランキングの集計のために使います。
    • 自宅の場所が分からないよう、軌跡のスタートとゴールの周り200mは取り除いてから送ります。
    • 記録を見られるのは、友達として承認した相手だけです。
  • 友達関係と、友達に送ったコース

4. 第三者への提供

運営者は、法令に基づく場合を除き、利用者の情報を第三者に販売・提供しません。広告や行動追跡（トラッキング）のための仕組みは使っていません。

5. 情報の削除

  • アカウントの削除：アプリの「友達 → 設定 → アカウントを削除」から、サーバーに保存したプロフィール・記録・友達関係・送ったコースをすべて削除できます。
  • 端末の中の情報：記録やコースはアプリの中で個別に削除できます。アプリを削除すると、端末の中の情報もすべて消えます。

6. テスト版（TestFlight）について

テスト版では、利用者が TestFlight から送ったフィードバック（コメント・スクリーンショット）とクラッシュの情報を、Apple を通じて運営者が受け取ります。

7. 変更

このポリシーを変更するときは、このページで知らせます。
